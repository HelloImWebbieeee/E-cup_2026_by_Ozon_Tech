# E-cup-2026-by-Ozon-Tech-Case-3

E-CUP 2026. Task 3: User search value. *Link: https://ods.ai/competitions/e-cup-2026-search*

Goal: predict the user’s total GMV for the next 30 days.
Metric: RMSLE.

Starting Session: August 13.
Local deadline: August 24.
Final polish: August 25–31.

Expected result: Good project for portfolio.
Own goal: Reaching top-3 in competition.

---

*Before starting*

1. Make sure that the correct PROJECT ROOT path is written in the config.py file;

2. Download the train.parquet dataset via the competition platform (link above);

3. Create a folder structure in the project: data\ raw\, and place train.parquet in the outermost folder;

4. If you have done everything correctly, you can run the notebooks in sequence: the remaining folders will be created automatically (via 01_data_composer.ipynb).
